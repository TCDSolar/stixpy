Add more ways to select data in `~stixpy.product.sources.science.ScienceData.get_data`: flat energies in keV and times as strings or `~astropy.time.Time` select individual bins, while nested [start, end] pairs sum ranges (for example ``[[4, 10], [15, 28]] * u.keV`` takes the bins whose centres lie in each range). The detector labels ``"top24"`` and ``"bkg"`` select the imaging and background detectors. Selecting detectors, pixels, energy bins or times that are not in the file raises an error; detector and pixel ranges may still span ones that are switched off, so ``[[0, 31]]`` sums every detector in the file.
