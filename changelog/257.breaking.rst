`~stixpy.product.sources.science.ScienceData.get_data` now applies the livetime and energy look-up table (ELUT) corrections by default (``livetime_correction=True``, ``elut_correction=True``), no longer returns the 0 keV bottom and open top energy bins, and returns a `~stixpy.product.sources.science.SelectedData` named tuple ``(counts, counts_err, t_norm, e_norm, livefrac, livefrac_error, elut_cor_fac, times, energies, rcr)`` instead of ``(counts, count_err, times, durations, energies)``. With the livetime correction the pixels are summed, so the pixel axis has length 1. Access the fields by name, e.g. ``data.counts``; set both corrections to ``False`` for uncorrected counts per pixel.
