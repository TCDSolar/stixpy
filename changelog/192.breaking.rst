`~stixpy.product.sources.science.ScienceData.get_data` now applies the livetime and energy look-up table (ELUT) corrections by default (``livetime_correction=True``, ``elut_correction=True``), no longer returns the 0-4 keV and open top energy bins, and returns a ten-element tuple ``(counts, counts_var, t_norm, e_norm, livefrac, livefrac_error, elut_cor_fac, times, energies, rcr)`` instead of ``(counts, count_err, times, durations, energies)``. Code that unpacks the old five values needs updating; set both corrections to ``False`` for uncorrected counts.
