Added support for STIX energy-calibration (CAL) FITS files. `~stixpy.product.Product` now recognises ``cal-energy`` files via the new `~stixpy.product.sources.cal.EnergyCalibration` class. A `~stixpy.product.sources.cal.find_energy_calibration_file_for_time` helper applies the documented strategy (on-board-ELUT match, ≥12 h recording duration, closest mid-time) to pick the daily calibration file applicable to a given instant or flare time range.

The selected file must also have its ``LIVETIME`` (primary FITS header) above a configurable threshold (default ``30 000 s`` ≈ 8 h). The search window spans ``[-window_past, +window_future]`` (defaults of 5 days back / 5 days forward) so older calibration files can be used when the most recent ones fall below the threshold. Candidates are scanned via HTTP range requests (`astropy.io.fits.open(url, use_fsspec=True)`) so only the winning file is fully downloaded. The three parameters (``min_livetime``, ``window_past``, ``window_future``) are keyword-only and overridable per call.
