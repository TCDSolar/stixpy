Add `stixpy.calibration.elut` as the single home for the energy lookup table (ELUT) code. `~stixpy.calibration.elut.get_elut_correction` now returns a `~stixpy.calibration.elut.ELUTCorrection` named tuple, ``(e_cor_high, e_cor_low, bins, bins_actual)``, which adds the science and calibrated energy bin widhts. ``stixpy.calibration.energy.get_elut`` is deprecated use `~stixpy.calibration.elut.get_elut` instead. The private copy of ``get_elut_correction`` in ``stixpy.calibration.visibility`` has been removed.
