Add livetime and energy look-up table (ELUT) corrections to `~stixpy.product.sources.science.ScienceData.get_data`, following STIX-GSW's ``stx_convert_pixel_data`` and ``stx_convert_spectrogram``, including the livetime uncertainty. The RCR (attenuator) state of each time bin is aligned to the jumps in the counts as in STIX-GSW and returned with the data; `~stixpy.product.sources.science.ScienceData.align_rcr` stores it as `~stixpy.product.sources.science.ScienceData.rcr_shifted`. A time range that spans an RCR change raises an error.
