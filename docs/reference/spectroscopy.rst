Spectroscopy ('stixpy.spectroscopy')
************************************

The ``spectroscopy`` submodule turns data selected with `~stixpy.product.sources.science.ScienceData.get_data` into
`sunkit_spex` spectra with their spectral response matrices. It needs the optional ``spectroscopy`` dependencies,
installed with ``pip install 'stixpy[spectroscopy]'``.
